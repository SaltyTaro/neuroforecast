**Round 2 is complete, September 20, 2026 IST. No replacement topic has earned promotion to the main competition entry.** The new numerical candidate, OxyGuard, failed its predefined gate. The reserve topics also retain substantial prior-work or public-data limitations. This is a negative selection result, not a claim that a competitive public-data project is impossible.

The round added **35 archived Europe PMC searches** and inspected relevant papers, GitHub releases, Zenodo datasets, and a GIN repository. Publications were bounded to September 19, 2026. The [source catalog](round2_sources.json) records 86 fetched resources with URLs, retrieval times, sizes, and SHA-256 hashes. Some broad full-text searches were noisy; neither these searches nor the earlier round constitute an exhaustive novelty review. Competitors' hidden Writeups were not accessed.

**The candidate that reached a numerical test.** OxyGuard asks which small region of a vessel-segmentation image a researcher should correct first to reduce error in a downstream oxygen model. It adds transport sensitivity to a learned segmentation-error estimate. This is more specific than a generic image-quality classifier, and it can be tested with public reference masks under a fixed review budget.

I downloaded and verified the [REAVER benchmark](https://zenodo.org/records/3340165): **36 images across six murine tissue types**, curated reference masks, and five automatic segmentation outputs. The 180 rows in the measurement CSV are repeated program/image records. They are not 180 independent specimens. Each tissue type was held out in turn while training the pixel model. All correction policies saw the same initial information, and only selected reference patches were revealed.

At four patches, or 6.25% of image area, full-field normalized model MAE was **0.014344** for OxyGuard and **0.014454** for the simpler predicted-mask-change rule. The relative improvement was **0.76%**, versus a required 20%; its descriptive paired-tissue interval was **−5.40% to +9.09%**. Only three of six tissues improved. With a longer assumed diffusion length, the proposed rule was worse. The review process reduced error, but the extra transport mechanism contributed little beyond the simpler learner.

The [full results](oxyguard_pilot_results.md), [frozen protocol](oxyguard_pilot_protocol.md), [compact result JSON](oxyguard_pilot_summary.json), and [runnable implementation](../tools/oxyguard_pilot.py) preserve the experiment. Five mathematical/information-flow tests passed; a saved-run audit verified 432 primary replays and 864 hidden-reference decision checks. These repeated checks do not increase the independent image count. Computation used only the local CPU.

Crucially, these are **computed oxygen fields from murine tissue images**, not measurements of oxygen delivery in organ chips. The surrogate assumes oxygen sources in all segmented vessels and does not infer perfusion or vessel patency. A real chip image was retrieved from AngioMT as an application example, but it lacks the reference measurements needed for validation. Those limits would remain even if the numerical gate had passed.

**Closest prior work and public evidence.**

- [DYNAMEX, 2026](https://doi.org/10.1021/acs.est.6c06087): kinetic exposure modeling and parameter fitting. Its validation tables include literature measurements, while other tables contain model simulations; these are not interchangeable training labels.
- [Simulating drug concentrations in PDMS microfluidic organ chips, 2021](https://doi.org/10.1039/d1lc00348h): experimentally estimates diffusion and partitioning for a Lung Airway Chip. This directly overlaps a generic calibration-plus-simulation pitch.
- [Hippocampal routing dataset 1](https://zenodo.org/records/4679064) and [stimulation dataset 2](https://zenodo.org/records/10257483): real compartmentalized neural recordings, with limited and incompletely resolved biological independence across releases.
- [Comparative MEA dataset, 2022](https://doi.org/10.1038/s41597-022-01242-4) and [the September 2026 threshold preprint](https://doi.org/10.21203/rs.3.rs-11004484/v1): both must be considered before proposing an activity-count reliability tool. The latter is a preprint, not established peer-reviewed consensus.
- [OCT flowmetry, 2025](https://doi.org/10.1038/s41598-025-10089-9), [raw-data release](https://zenodo.org/records/14293638), and [processed PIV release](https://zenodo.org/records/14251838): useful data, but not a large fault-labelled cohort.
- [AI-enabled sickling dynamics, 2026](https://doi.org/10.1039/d6lc00108d): an existing dense-RBC segmentation and counting method.
- [Machine-vision-guided longitudinal MPS, 2026](https://doi.org/10.1002/advs.76256): meaningful exposure-history biology, with raw data available on request.
- [REAVER, 2020](https://doi.org/10.1111/micc.12618), [AngioMT, 2024](https://doi.org/10.1371/journal.pone.0299160), [morphology-to-function ML, 2023](https://doi.org/10.1007/s10439-023-03177-2), and [VC-Net, 2025](https://doi.org/10.1016/j.cmpb.2025.108953): establish substantial overlap for generic vascular-image projects.
- [Segmentation uncertainty and pulmonary hemodynamics, 2019](https://doi.org/10.1098/rsif.2019.0284), [learned geometric uncertainty, 2021](https://doi.org/10.1016/j.cma.2021.114038), and [PULASki, 2025](https://doi.org/10.1016/j.media.2025.103623): uncertainty propagation and probabilistic vessel segmentation are established ideas.

**What changes in the search strategy.** Two selection gates now show that a useful predictor does not necessarily create a useful new decision policy. The next candidate should start with a public dataset containing a directly measured functional outcome or an explicit intervention result, with defensible independent units. The core question should survive comparison with a strong simple method before adding adaptive selection, a digital-twin layer, or a large interface. A simulated endpoint may support engineering development, but it must not carry a claim of biological validation.

I am not recommending the earlier image-QC classifier merely because these candidates failed; its published overlap remains. There is no justified “best winning topic” yet. What this round provides is a reproducible exclusion of another weak mechanism, a more accurate public-data map, and an explicit bar for the next selection.
